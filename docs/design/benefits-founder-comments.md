# 社長の中央コメント — 2026-10-22

中央に登場した社長が、吹き出しで挨拶します。コメントは次の順に8秒間隔で切り替わり、最後のコメントで止まります。「次のコメント」でも切り替えられ、操作後は自動切り替えを止めます。

1. お待たせしました！ここからは僕がご案内します。
2. 声も、トーク設計も。営業現場の知見を詰め込んでいます。
3. 結果を見て、一緒に改善。その積み重ねが大切なんです。

音声機能・音声ボタン・読み上げ用ファイルは追加していません。既存の通話サンプルは従来のままです。
