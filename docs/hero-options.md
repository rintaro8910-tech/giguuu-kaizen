# ヒーロー画像の全案

`http://localhost:8000/hero-options.html` で、トップページ・採用ページの画像候補を一覧表示します。

画像のボタンから拡大表示、各カードから実際のページでプレビューできます。プレビュー下部の「この画像を使う」で、そのブラウザの選択を保存します。トップページと採用ページの選択は別々です。「元の画像に戻す」または一覧の「保存した選択をリセット」で解除できます。選択はブラウザ内に保存され、HTMLの既定画像や他の人のブラウザには反映されません。

2026-10-14 時点では72案・88画像ファイルを登録しています。同じ案のPNG/JPEGと解像度違いは1カードにまとめ、JSONの`files`に全パスを保持しています。参照サイトのキャプチャ、QAスクリーンショット、背景ノイズ、同じ素材を複製したLPフォルダは候補として表示しません。

画像の追加後はプロジェクト直下で `python3 scripts/build_hero_catalog.py` を実行すると `hero-options.json` と `hero-options-data.js` を更新できます。対象は `assets/hero`、`assets/recruit`、`assets/telemo-blender`、`output/ui-concepts-10`、`output/ui-concepts-10b`、`assets`直下のhero画像、プロジェクト直下の画像です。

## 確認

- 72案の画像と一覧・プレビュー用ファイルのHTTP 200を確認。
- JavaScript構文と `git diff --check` を確認。
- Chromeで一覧、検索、シリーズ絞り込み、拡大表示、採用ページへの差し替え、選択保存、元の画像への復帰、トップページへの差し替えを確認。
- Chromeの390px幅で横スクロールが発生しないことを確認。シリーズ選択欄をスマートフォン幅で全幅に調整。
- 既存ページの画像以外の内容を使い、プレビュー時のみ上部画像の下に文章を配置して重なりを解消。
