## 2. ビジュアルテーマと雰囲気

### 2.1 場面転換：暗 → 明 → 暗 → 明
ページの明るさを「場面」として切り替え、広告の熱量と医療資料の冷静さをぶつからせずに両立させている（`visual/top-1440-full.jpg`）。

| 場面 | セクション | 明度 | 役割 |
|---|---|---|---|
| ① ブランドの舞台 | Hero → Achievements → KwSection（CM） | 濃紺 #0F1B43〜#182963 | 有名人の CM の世界観、権威バッジ、最初の CTA。感情に訴える |
| ② 手紙 | Message | 淡い青灰の写真 | 当事者の一人称の語り。明朝で組み、字間を広く取る |
| ③ 医療資料の面 | EarlyDetectionCases → ScanCtaCompact → About → Benefits → Doctors | 白〜淡青 #E9F6FF / #E1EBF2 | 実例、仕組み、エビデンス、出典の注記。理屈で納得させる |
| ④ 決断の舞台 | PurchaseCta | 濃紺のスポット照明 | 価格と購入。決断の瞬間だけブランドの世界に戻す |
| ⑤ 安心と回遊 | CustomerSupport → … → Consider | 白・グレー #F5F5F5・グラデ | 相談、手順、店舗、メディア、FAQ、記事 |
| ⑥ 締め | フッター CTA 帯 → フッター | 青 #3B5DB3 / #2B4A99 | 相談の CTA と法的な注記 |

### 2.2 医療の信頼と購買の両立
- **信頼**: 明朝の見出し（濃紺または金）、大きな数字と月桂冠、出典の※注記、医師の顔写真と実名、白い面、控えめな動き。
- **購買**: オレンジのグラデーション CTA を 1 色に絞る、固定ヘッダーに常に「購入に進む」を置く、価格の打ち消し線と割引タグ、電話と LINE の相談導線、下部の常駐バナー。
- オレンジは主 CTA とキャンペーンの文言にしか使わない。それ以外は青の濃淡で統一する。こうすると「次に押すもの」が迷わず見つかる。

### 2.3 キーワード
`濃紺の舞台照明` `白い医療資料` `明朝の権威` `金の月桂冠` `大きな数字と小さな※` `オレンジ 1 色の CTA` `動かない誠実さ` `相談できる安心`

### 4.4 数字の見せ方
- 型は「**大きな数字 + 小さな単位 + 前後の『約』『以上』**」。単位は数字のおよそ 0.4〜0.5 倍（54 に対して 26、推定の比）（`visual/top-1440-sec08-Benefits.jpg`）。
- 権威を示す数字（2,500以上、約50機関、世界初※）は**金の月桂冠**で挟む。実装は SVG 画像で、alt が付いている（`visual/top-1440-sec02-Achievements.jpg`）。
- 機能的な数字（電話、日付、Q、ステップ）は Inter に `lnum tnum` を付ける。
- 価格は Noto の太字。並び順は、打ち消し線の旧価格（小）→ 割引後の価格（特大、定期便はコーラル）→「円」（小）→ 枠線の割引タグ → paidy の月額（`visual/top-1440-sec10-PurchaseCta.jpg`）。
- グラフの強調値は、吹き出しの形のラベルを濃紺の地に白抜きで置く（92.9%）。

### 4.5 縦書き（SP の Hero）
- SP の Kv の縦書きコピー（「自宅でかんたん、/がんリスク検査。」）は**画像に焼き込んである**（`kv_sp-750.avif`、390×416、alt あり）。`writing-mode` を使った要素はページ内に 0 件（再計測）（`visual/top-390-sec01-Kv.jpg`）。
- 再現では HTML のテキストで組むこと: `writing-mode: vertical-rl;`、明朝ではなくゴシック寄りの白文字（画像を見て推定。細めのゴシックで字間が広い）、右上に置き、2 行、行間は広め、`text-orientation: mixed`、句読点は縦書き用の約物にする。

### 4.6 注記（※）の組み方
- 本文や見出しの主張の直後に `※1` `※2` `＊` を**上付き**で付ける（`約8割※1` `10種※2`）。見出しの中でも省略しない。
- 注記の本体はセクションの末尾か CTA の直下にまとめる。10〜12px、line-height 1.5、0.05em、#838383（淡い面では #646464 を推奨）。
- 種類: 出典（国立がん研究センター、論文誌名）、対象の条件（女性は9種、男性は8種）、調査主体（第三者機関調査）、例外（一部離島を除く）、検査の位置づけ（診断ではない、LDT）。
- フッターには、トップを含む全ページに LDT 検査の長い注記が太字で入る（再計測: トップのフッターにも「LDT」あり）（`visual/footer-1440.jpg`）。

### 8.2 動かすもの・動かさないもの
- **動かす**: 「量の実感」を出したいところだけ（SP の症例マーキー）と、一人称のメッセージの静かな入場。
- **動かさない**: ヘッダー（縮まない、隠れない）、カード（持ち上げない、影を足さない）、主 CTA（拡大しない、揺らさない）、パララックス、数字のカウントアップ、背景動画の演出。About の microRNA のループ動画（webm、muted・loop・playsinline、controls なし）は例外的に置かれている。
- ホバーは「暗くする」だけにそろえる。

### 8.3 reduced-motion
`prefers-reduced-motion: reduce` のとき、マーキーは停止、フェードは opacity 1 で即時に表示、バナーとボタンの transition は none。**2nd nav の slideDown だけは対象から漏れている**（再現では含める）。

## 10. コピーとトーン

| 観点 | ルール | 例（短く引用） |
|---|---|---|
| 文体 | です・ます調。科学的に慎重な文末 | 「〜が確認されています」「〜と言われています」「〜可能性」 |
| 語彙 | 「がんリスク」「リスク検査」「スクリーニング」で統一する。「診断」「がんがわかる」は使わない | 「自宅でかんたん、がんリスク検査。」 |
| 範囲を数字で | 検出範囲や実績を具体的な数字で言う | 「1度に10種＊の がんリスクをまとめて検査」「ステージ1から」 |
| 主張と※ | 主張は大きく言い切り、根拠と条件は必ず小さく添える | 「世界初※」「約8割※1」 |
| 二段構え | 不安を受け止めてから解決を示す | 「一方で、…期間は短く」→「定期的な検査で…重要です」 |
| 寄り添いの否定形 | 否定形で安心させる | 「『検査したら終わり』ではありません。」 |
| 生活者の声を見出しに | 疑問をそのまま見出しにする | 「追加検査はどの病院に行けばいいの？」 |

## 11. Do / Don't

### Do（守ること）
1. 明度で場面を切り替える。ブランドと決断は濃紺、説明と安心は白と淡青。
2. オレンジは主 CTA とキャンペーン文言だけに使う。CTA は 1 画面に 1 つまで。
3. 感情や主張の見出しは明朝、情報を整理する見出しと UI はゴシック。和文には `palt` と 0.05em。
4. 数字は「大きな数字 + 小さな単位 + 約／以上」。権威の数字は月桂冠で挟む。
5. 主張には必ず※を付け、セクションの末尾に注記をまとめる。
6. 本文の幅は 992px、セクションの縦余白は 128 / 80、見出し → 内容は 64 / 48。
7. 写真とカードは角丸 0、影はごく薄く。ホバーは「暗くする」だけ。
8. 主 CTA の間に、電話と LINE の相談を必ず挟む。
9. 主力商品を 1 つだけ大きく見せる序列（メニューでもカードでも）。
10. 医師や監修者は、顔写真・実名・所属・役職をセットで出す。

### Don't（避けること。サイトの弱点は再現しない）
| 避けること | 理由 | 改善案 |
|---|---|---|
| ページに H1 を置かず、Hero のコピーを画像に焼き込む | 見出しの構造と SEO が弱い | Hero のコピーを HTML の H1 にする（SP の縦書きも `writing-mode` で） |
| ハンバーガーを DIV で作り、名前も状態も持たせない | キーボードとスクリーンリーダーで操作できない | `<button aria-expanded aria-controls aria-label="メニュー">` |
| フォーカスのスタイルがブラウザ既定のまま | 濃紺や青の地で見えない | `:focus-visible` に 2px のオフセット付きリング（白地では #0063AC、濃い地では白） |
| 白の小さな文字を CTA グラデの終端（2.47）や LINE 緑（2.68）に載せる | AA を満たさない | 文字を 16px・700 以上にするか、地の色を暗くする |
| #838383 の 10px の注記を淡青やグレーの地に置く | 3.1〜3.5 で読みにくい | 淡い面では #646464・12px 以上にする |
| テキストリンクやドットのタップ領域が 44px 未満（SP では 90 個中 46 個） | 押しにくい | 余白を含めて 44×44 を確保する |
| 常駐バナーが SP 画面の約 15% を覆い、FV に重なる | 本文を隠す | FV を過ぎてから出す。1 枚にまとめる。高さは 64px 以下にする |
| UA で SP と PC を分け、タブレットで本文が切れる | 768〜1319px で崩れる | 1 つのツリーを幅のブレークポイントで組み替える |
| 字間を広く取った明朝の見出しが、SP で「調 / べ、」のように 1〜2 文字だけ次の行に落ちる | 見栄えと可読性が落ちる | `word-break: auto-phrase` か、`<wbr>` による手動の改行。SP では字間を 0.05em 以下にする |
| 旧テンプレートの見出し（グレーのゴシック 34px）と新系統を混ぜる | 世代の混在 | 新系統（#004380、明朝とゴシックの使い分け）に統一する |
| CTA の文言を何系統も混ぜる（「購入に進む ▶」「購入はこちら」） | 一貫しない | 「マイシグナルを購入する」に統一する |
| 2nd nav の slideDown が reduced-motion の対象から漏れる | 配慮が不完全 | すべての animation を `prefers-reduced-motion` で止める |

## 14. 計測メモ

### 14.1 計測方法
- 元データ: `visual-analysis.md`（視覚・構造・動き。Chromium、PC 1440 / SP 390、iPhone UA、計測タグを遮断）と `tokens.md`・`tokens/*.json`（computed style と配信 CSS の静的集計。5 ページ）。
- この DESIGN.md のための再計測: 2026-10-05、Playwright Chromium。PC は 1440×900 と 1920×1080（デスクトップ UA）、SP は `devices['iPhone 13']`（390×664、iPhone UA、isMobile、DPR3）。対象は `/`、`/corporation`、`/products/scan`。ページの間は 2 秒以上あけた。robots.txt の Disallow には行かず、送信・購入・ログインはしていない。
- 主要なスクショ（top の 1440 / 390 のセクション、ヘッダー、CTA のホバー、FAQ、カルーセル、フッター、常駐バナー、メガメニュー、SP メニュー）は目で見て記述を確認した。

### 14.3 推定値
- タイプスケールを「2px 刻みの本文帯 + 見出し帯」とみなす解釈、4/8 系のスペーシングスケール。

- CTA グラデの終端の改善案 `#E8641E`（コントラストは計算していない）。
- タブレット向けの設計がないこと。
