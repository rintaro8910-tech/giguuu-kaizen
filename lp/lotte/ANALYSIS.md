# ロッテ公式トップ デザイン分析 → TELEMO への移植要素

- 対象：https://www.lotte.co.jp/（ローカル再現版 `~/lp-work/refs/lotte`、取得・確認日 2026-10-13）
- 根拠：`~/lp-work/refs/lotte/shots/` の PC(1440)/SP(390) スクショの目視確認と、Playwright による computed style・CSS ルール・スライダー設定（Splide）の実測。
- 数値は実測値。「不明」は計測・確認できなかったもの。

## 1. ファーストビューの構図（メインビジュアル）

- **2段ヘッダーのすぐ下に、全幅の画像帯**。PC は 1440×540px（ヘッダー136px＋帯540px＝676px で FV の約75%）、SP は 390×305px。角丸・影・枠なしのベタ配置。
- **キャッチコピーを HTML で重ねていない**。商品写真・コピーは画像に焼き込まれていて、FV の「主役」は画像そのもの。1スライドに商品2つを左右に並べる構図もある（PCの1枚目）。
- **操作 UI は帯の下、中央に一列**：赤い山形の矢印（10px）‹ ・○ドット5つ（13px、1px赤枠、選択中は赤塗り）・一時停止ピル（30×17px）・矢印 › 。帯の上には何も載せない。
- 動き：Splide `type: loop`、**自動送り 6,500ms**、**スライド切替 500ms**、ホバーで一時停止（`pauseOnHover: true`）。ドットと矢印の hover 変化はほぼなく、操作 UI は控えめ。
- 帯の直後は白地のお知らせリスト（720px 幅）。FV の下端（PC 900px 時点）にリストの先頭が少し見え、下へ読み進める動機になっている。

## 2. 書体・サイズ比・字間、英字と和文の組み合わせ

- font-family：`Roboto, "Noto Sans JP", sans-serif`。Roboto のみ Web フォント、和文は端末フォント。**body の既定が 14px／weight 700**（太字が基本）。INFO の一覧だけ 400 にして読み物っぽくしている。
- **セクション見出し（全セクション共通 `h2.wrapTitle`）**：英字を上（Roboto 900・30px・uppercase・字間0.06em・主色の赤）、和文を下（16px・700・**字間0.24em**・グレー #6b6b6b）に中央で縦積み。**サイズ比 30:16（約1.9:1）、SP でも縮小しない**。見出し下の余白は 30px。例：NEW PRODUCTS／新商品、FIND BRANDS／ブランドを探す。
- **項目ラベルにも英和の2段**：FIND PRODUCTS の各カテゴリは、英字（13px・900・グレー）の下に和文（16px・700・字間0.12em・#333）、左に赤い線画アイコン（30×23px）。
- ナビは 16px・700・字間0.12em、サブナビ 14px・700・字間0.12em。全体として**大きな文字では目立たせず**、字間を広めにとった太字を小さめに組み、写真と色面で見せている。
- 本文：ABOUT のリード文は 16px・700・行間32px（2.0）の中央揃えで、`br` で行を整える。

## 3. 配色ルール

| 役割 | ロッテ | 使い方 |
|---|---|---|
| 主色 | 赤 #dd1d18 | **1色だけで、面（ナビ帯・ABOUT 背景・フッター下段）と小さなアクセント（英字見出し・タグ・丸シェブロン・ドット・選択バー・hover 文字色）の両方を担う** |
| 地色1 | 白 #fff | お知らせ・FIND PRODUCTS・CM・INFO |
| 地色2 | ベージュ #efece7 | NEW PRODUCTS・FIND BRANDS・CAMPAIGN（白と交互） |
| 淡色カード | #f5f4f0 | ABOUT の大カード |
| 文字 | #333／サブ #6b6b6b／日付 #666 | |
| 罫線 | #d3d3d3（1px） | リスト・タブ |

- **影・グラデーション・ガラス表現は使わない**。立体感を出さず、角丸 5〜6px のフラットな面で構成。
- hover は「主色の文字色に変える」が基本（transition color .2〜.25s）。

## 4. 余白のリズム、グリッド、セクション間の切り替え

- **セクション同士の margin は 0**。上下 padding（PC 40〜70px、SP 25〜58px）と**背景色の切り替え**で区切る。区切り線・波形・斜めの切り替えは使わない。
- 背景の並び：白（お知らせ）→ベージュ（NEW PRODUCTS）→白（FIND PRODUCTS）→ベージュ（FIND BRANDS）→白（SNS）→**赤ベタ（ABOUT）**→白（CM）→ベージュ（CAMPAIGN）→白（INFO）→赤（フッター）。同じ色が続かず、赤ベタはページ後半に1回だけ置かれる。
- コンテンツ幅：基本 1024px（1440 で左右 208px）、ヘッダー 1104px、リスト 720px。
- グリッド：FIND PRODUCTS 4列（gap なし、SP 2列）、ABOUT 3列（gap 36px、SP 2列）、FIND BRANDS **全幅 4列×3行・隙間なし**（SP 2列・gap 8px）。
- カルーセルは NEW PRODUCTS（PC 5枚）、CM・CAMPAIGN（PC 3枚 center、左右のカードが画面端で切れて見える）。SP は 1枚＋左右 15vw の隣がのぞく。

## 5. 写真・イラスト・商品の見せ方、カード／タイルの形

- **NEW PRODUCTS**：白い角丸5pxの枠（aspect 54:37）に商品を `contain` で小さめに収め、商品名は枠の下に左揃え 14px。影なし。
- **FIND PRODUCTS**：カードの枠を見せず白地に商品だけを置く。hover で枠線（3px）が主色になる。
- **FIND BRANDS**：2:1 の画像タイルを**隙間なく敷き詰めたモザイク**。各タイルの色がばらばらで、にぎやかさがある。PC は hover で黒60%の幕＋白い名称＋外部リンクアイコン（opacity .3s）、SP は名称を常に画像の下に出す。
- **ABOUT**：赤ベタの上に白いカード。1枚目は3列分のワイドバナー（左に写真、右に赤の 18px 見出し＋黒の注記）、残りは画像上（20:11）・ラベル下（70px の白帯、右端に丸シェブロンか外部リンクアイコン）、角丸6px。
- **SNS バナー**：角丸の枠の中に、**右向き矢印形のリボン帯**が横切り、SNS の丸アイコンが**上下にずれて重なり合う**。コーポレートサイトの中で、ここだけ遊びのある見せ方をしている。
- CM／CAMPAIGN：16:9 のサムネ（角丸なし）＋下に太字タイトル 16px＋グレーの補足 14px。

## 6. 導線（ボタン・文言の置き方・位置）、ホバー・スクロールの動き

- **「丸シェブロン＋太字の文言」を全体で共通の導線にしている**：直径23pxの主色の丸に白い山形、右に 14px・700 の文言（「新商品一覧」等）。枠も背景もないテキストリンクで、**各セクションの最下部中央**に置く。お知らせ・ABOUT カードの右端にも同じ丸シェブロン。
- 外部リンクは主色の「□↗」アイコンで区別。
- フッターのボタンは白2px枠・角丸5px・190×43px、右端に山形。hover で白地＋主色文字に反転。
- お知らせ・INFO：主色ベタの小さなタグ（12px・900・字間1.8px、角丸なし）＋本文＋右端の丸シェブロン＋1px 罫線のリスト。hover で文字が主色に。INFO はタブ（選択中は下端中央に 62×4px の赤バー、.3s）。
- ナビ：hover で項目の下端中央に白バー（61×4px）。「商品情報」は帯と同じ赤系のメガメニューを開く（アイコン＋ラベルの格子、白枠ボタン）。
- SP：ヘッダーは 62.5px で固定。右上に「≡＋MENU」ラベル付きボタン（主色）、ドロワーは主色背景（height .3s）。
- **スクロール連動のフェードイン等はない**。動きはスライダー、hover の色や透明度の変化（.2〜.5s ease）、トップへ戻るボタンの出現（200px以降）だけ。

## 配色の置き換え（ロッテの配色ルール → TELEMO ブランド色）

ロッテは「主色1色が面とアクセントを兼ねる＋白／ベージュの交互＋影なし」。TELEMO では主色の役割を、面はネイビー、小さなアクセントはティールに分ける。緑は成約導線だけに使う。

| ロッテ | 役割 | TELEMO |
|---|---|---|
| #dd1d18（面：ナビ帯・ABOUT・フッター） | 主色ベタ面 | ネイビー **#0d2240** |
| #dd1d18（英字見出し・タグ・丸シェブロン・ドット・選択バー・hover） | 主色アクセント | ティール **#0e7c86**（白地でコントラスト約4.9:1） |
| —（ロッテにない） | 成約ボタン | 緑 **#2ed16b**（文字はネイビー。白文字は低コントラストのため使わない） |
| #fff / #efece7 | 地色の交互 | #fff / 淡いグレー **#edf2f3** |
| #f5f4f0 | 淡色カード | #f5f8f8 |
| #333 / #6b6b6b | 文字／サブ | #2a3442 / #5f6b76 |
| #d3d3d3 | 罫線 | #d3dadd |
