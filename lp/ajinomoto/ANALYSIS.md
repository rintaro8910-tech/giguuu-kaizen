# 味の素「なんと、紙！になったンダ。」LP 分析 → TELEMO への移植要素

- 参照元: https://www.ajinomoto.co.jp/aji/recipe/kamipkg/（2026-10-13 取得）
- ローカル再現: `~/lp-work/refs/ajinomoto`（`http://127.0.0.1:8792/aji/recipe/kamipkg/`）
- 見たスクショ: `refs/ajinomoto/shots/pc-1440-fv.png` `pc-1440-full.png` `sp-390-fv.png` `sp-390-full.png`、共通ヘッダー/フッターは `live-*-header.png` `live-*-footer.png`
- 数値の出どころ: 「実測」はブラウザの計算済みstyle、またはスクショのピクセル採取。「CSS」は style.css の記述。どちらでもないものは「目視」と書く。

ページ構成（上から）: 共通ヘッダー → Hero（`.pkg-hero`）→ 説明（`.pkg-desc`）→ 不安と解決（`.pkg-feature`）→ コラム・アコーディオン（`.pkg-column`）→ 開発者の思い（`.pkg-voice`）→ 共通フッター

## 1. ファーストビューの構図

- **Hero（`.pkg-hero`）の高さ**: PCでは 440px（y=124〜564）。1440×900 の画面の約半分で、全画面のヒーローではない。下の「説明」セクションの上部（2分割の背景と見出し文）が最初の画面に入る（実測）。
- **左右の配分**: 左のテキスト塊は x≈270 から始まり、幅は約360px。右半分（x≈690〜1290）に立体の紙製パンダと商品パッケージを大きく置く。ビジュアルが主役で、テキストより面積が大きい（目視）。
- **キャッチの置き方**: 見出しは2行で、そのうち1語「紙！」だけ手書き風にし、約1.5倍の大きさで斜めに傾けている。残りの文字は丸みのあるゴシックで、字間を広く取る。サブコピーは3行で、行送りは約47px（文字の約2.3倍）。注記は10px前後で最後に置く（目視・hero_title.png 440×179）。
- **遊びの小物**: 右上に地球のオブジェを糸で吊るしている。画面の端から何かが入り込む見せ方（目視）。
- **動き**: スライダーもアニメーションもない。静止画1枚で見せる（main.js で確認できた動きはアコーディオンの開閉だけ）。
- **SP（390px）**: 縦に「見出し → ビジュアル → サブコピー」の順で積む。見出しは画面幅の約85%まで拡大し、ビジュアルは全幅で置く（sp-390-fv.png）。

## 2. 書体・サイズ比・字間・英字と和文

- **書体**: 本文は Noto Sans JP（400/700）（CSS）。見出しとリード文はほとんどが画像化した文字で、丸みのあるゴシックに広い字間をつけている。
- **サイズ比（目視・PC）**: Hero見出しの1文字が約44px、サブコピーが約20px で、約2.2:1。セクション見出しは約30px、本文は16px で、約1.9:1。数値パネルでは「34%」「12t」の数字がラベルの約2倍の大きさ。比較グラフの注記「約**1.4**倍」も、数字部分だけ約1.6倍にしている。
- **字間**: 見出しやリード文は 0.12〜0.2em と広い（CSSの `letter-spacing:.125em`、目視）。本文は 16px、行の高さ 27px（1.7）、字間 0.045em（吹き出し部分の実測 0.72px）。
- **英字と和文**: LPの本文に英字の見出しは使っていない。英字は共通ヘッダーの「Eat Well, Live Well.」とフッターの「PAGE TOP」だけ。**和文が主役で、英字は小さなラベル程度**にとどめている。
- **名前の組み方（Voice）**: 「宮坂**さん**」のように、名前を大きく、「さん」を小さく組む。所属は小さな赤字（目視）。

## 3. 配色ルール

| 役割 | 味の素の色 | 使っている場所 |
|---|---|---|
| 主色（ブランド・自社の主張） | 赤 `#e60012`（実測） | Feature の8px枠、全幅の帯、見出しの文字、グラフの自社の棒、名前 |
| 強調（1か所ずつ） | 黄 `#fdd23c`（実測） | キーワード背後の不定形バッジ、マーカー線（文字の下半分） |
| 比較対象（他・従来） | 灰カーキ `#9f9d89`（実測） | グラフの「従来」「一般的」の棒と文字 |
| 補助の情報エリア | 深緑 `#0f7765`（CSS） | コラムの見出しの一部、外枠カードの罫 |
| ビフォー/アフター | `#eceaea` / `#f5e1e2`（CSS・実測） | 説明セクションの背景を左右50%で塗り分け |
| 面・吹き出し | `#f4f4f4`（実測）、白 | 吹き出し、白いパネル |
| 文字 | `#333`（実測） | 本文 |

**ルール**: 自社と主張は主色、他社と従来は灰、強調は黄を1語だけに使う。補足情報は別の色（緑）のエリアに分ける。背景色の切り替えでセクションの意味（ビフォー/アフター、補足）を示す。

## 4. 余白・グリッド・セクションの切り替え

- **コンテナ**: 最大 960px（CSS `max-width:960px`）。コラムのパネルは約920px（x=260〜1180）。
- **セクション間に白い余白を挟まず**、背景の切り替えで区切る。2分割の背景 → 赤い8px枠 → 写真背景（`#c7d7db` に写真）→ 白、の順（CSS・目視）。
- **Feature**: 外周を8pxの赤枠で囲み、見出しの帯の下にも8pxの赤線（CSS `border-bottom:8px`）。3列は等幅（33.33%）で、列の間を赤い縦罫で区切る（CSS）。本文の上下余白は 32px / 76px（CSS）。
- **境界にまたがる要素**: 八角形のカードが赤帯と白地の境界をまたぐ。「もっと見る」ボタンも白パネルの下辺をまたぐ。バッジ「不安」は見出しの帯の上下の罫をはみ出す（目視）。
- **V字の切り替え**: コラムの中で、白い面から薄い灰の面へ山型（V字）に切り替える。Voiceの見出しの下の赤罫にも小さなV字の切り欠き（吹き出しのしっぽ）がある（目視）。
- **SP**: 3列を「文＋イラスト」の横並び1行に組み替え、左右を交互にする。八角形カードは縦に積み、横に**縦書き**のリード文を添える（sp-390-full.png）。

## 5. 写真・イラスト・商品の見せ方、カードの形

- **主役ビジュアル**: Hero に立体の紙製キャラクターと商品を一緒に置く。商品だけを見せない。
- **マスコットが覗き込む**: 数値パネルの右端、八角形カードの右下、フッターの PAGE TOP タブの上からパンダが顔を出す。どれも**要素の角から少しはみ出す**置き方（目視）。
- **イラスト**: 線画の人物に、主色と強調色を少しだけ塗る（Feature の3人、Voice の開発者）。
- **カードの形**: 角を切った八角形（Feature）、角丸8pxの吹き出し（Voice。PCでは実測 radius 8px、padding 35/30/30px）、1px緑罫・角丸8pxの外枠カード（コラム。見出し行と本文を1px罫で分け、項目の間は破線）。
- **グラフ**: 自社は主色の棒、他は灰の棒。点線で高さをつなぎ、「約1.4倍」「約2.6倍」の注記を矢印の横に置く。グラフの下に、結論の文をマーカー付きで繰り返す。

## 6. 導線・ボタン・ホバー・スクロールの動き

- **LP本体に購入・問い合わせボタンはない**（このLPは告知の1ページ）。導線はアコーディオンの「もっと見る」（白地、1px `#d2d2d2` 罫、角は9999pxで丸め、218×40px、18px、右に∨）と、閉じるための「×」の円ボタン（実測）。
- **ボタンの位置**: パネルの下辺の中央で、上下にまたがる位置（目視）。
- **共通ヘッダー**: 左にロゴと社名（縦罫で区切る）。右上の段に**枠線だけの角丸ピル型ボタン**（赤・緑・黒の枠）とテキストリンク。下の段は「›」付きの太字ナビ。右端に検索と「MENU」の正方形ブロック（縦罫で区切る）。PCの高さは124px、SPは62px（実測）。
- **ホバー**: 「もっと見る」はホバーしても色が変わらない（実測で背景・文字・罫が同じ）。
- **動き**: アコーディオンは max-height で開閉（CSS `transition .3s cubic-bezier(.215,.61,.355,1)`）。スクロール連動の演出はない。**遊び心は動きではなく、イラスト・マスコット・手書き風の文字で出している。**
- **フッター**: 1行のリンクと©表記、SNSアイコン、パンダが覗く「PAGE TOP」タブ（live-pc-1440-footer.png）。

## TELEMO に移植する8要素

配色の置き換え: 赤 `#e60012` → **ネイビー `#0b2a3c`**（枠・帯・見出し）／ 黄 `#fdd23c` → **緑 `#2ed16b`**（バッジ・マーカー・強調1語）／ 深緑 `#0f7765` → **ティール `#13807f`**（補足エリア・外枠カード・キーワード）／ 灰カーキ `#9f9d89` → **灰 `#9aa6ae`**（他社・人による営業）／ 2分割 `#eceaea`・`#f5e1e2` → **`#eceff1`・`#e2f3ef`**

| # | 移植する要素 | 味の素の場所 | TELEMO の適用先 |
|---|---|---|---|
| 1 | **画面の半分ほどの高さのHero。左に文字、右に大きな主役ビジュアル。手書き風の1語を約1.5倍で傾け、画面の端から吊り下がる小物を置く** | `.pkg-hero`（PC 440px、「紙！」、右上の地球） | Hero：キャッチの『仕組み』を手書き風に。右に管理画面風UI（カウンター・通話ログ・アポ獲得の通知）を大きく置き、通知カードを吊り下げる |
| 2 | **背景を左右50%で塗り分けたビフォー/アフター。白い数値パネルにマスコットが覗く** | `.pkg-desc`（`#eceaea` / `#f5e1e2`、34%・12t のパネル、パンダ） | Features①：左＝人による営業（灰）、右＝TELEMO（ティールの薄色）。数値パネル「約5倍」にロボットが覗く |
| 3 | **比較棒グラフ（自社は主色、他は灰、点線、「約◯倍」の注記）＋グラフ下でマーカーを引いた結論文** | `.pkg-feature-graph` / `.pkg-feature-txt` | Features①：月間コール数 4,400 vs 22,000。Features②：1コール単価 約20円 vs 約15.9円 |
| 4 | **太枠フレームで囲んだ「問い→答え」ブロック。白帯の見出しにキーワードバッジ、等幅の列を縦罫で区切り、マーカーを引く** | `.pkg-feature`（8px枠、「不安」バッジ、3列＋縦罫） | Features②：他社AI vs TELEMO（「違う」にバッジ）。Features③：対象シーン8つのタイル（4列×2、縦罫・横罫） |
| 5 | **主色の全幅帯と、その境界をまたぐ角を切った白カード** | `.pkg-feature__sub-title` ＋ `.pkg-feature-point-card` | Pricing：ネイビーの帯「料金はシンプル。」の境界に、初期費用と月額の八角形カードをまたがせる |
| 6 | **グレーの吹き出し、線画の人物、名前（「さん」を小さく）、左右交互、見出し下の罫にV字の切り欠き** | `.pkg-voice` | Testimonials：「TELEMOをつくったひと。」青木一平さん、お客様の声の枠（TODO） |
| 7 | **淡色背景の上の白パネル、下辺をまたぐピル型ボタンで開閉。開くと外枠カード（見出し行と本文を罫で分け、項目の間は破線）** | `.pkg-column`（もっと見る / ×、`.pkg-env-card`） | FAQ（details/summary の外枠カード）。CTA の導入の流れ（STEP01〜06）は外枠カードの作り、音声デモはパネルとまたがるボタン |
| 8 | **ピル型の枠線ボタンと「›」付きナビ／PAGE TOPタブに覗くマスコット／縦書きの添え文** | 共通ヘッダー・フッター、SPの縦書きリード | Header（枠線ピル「無料で相談する」）、Footer（PAGE TOPにロボット）、TELEMO川柳を縦書きの短冊で、角からロボットを覗かせてセクション間に置く |

### 持ち込まないもの
味の素の文言・商品名・ロゴ・写真・イラスト・パンダ、会社情報、計測タグ。マスコットは TELEMO 資料にあるロボットを、HTML/CSS/SVG で新しく単純な形に描く。
